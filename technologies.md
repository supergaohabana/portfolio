## Vitrivo — visual editing & catalog integration

- **Application:** JavaScript, TypeScript, Node.js, Fastify and Vite.
- **Local data:** IndexedDB, Service Workers and PWA workflows.
- **Cloud:** Supabase synchronization, Render backend and Firebase Hosting.
- **Images:** IMG.LY background removal with WebAssembly, Sharp and WebP processing.
- **Design:** Google Stitch explorations and implemented interface iterations.
- **Validation:** Node.js test runner and browser automation; offline, storage and synchronization failure scenarios.
- **AI retouch integration:** Puter SDK. The integration was published and tested with a simulated generation flow; the project record does not establish a completed real generation for this review.

## Commerce analytics & automation

- **Analytics:** GA4 and the Google Analytics Data API for traffic, search and event analysis, combined with ERP information for business investigations.
- **Google integrations:** Drive API, Sheets API, OAuth and service accounts for collecting data, writing KPI records and organizing reports.
- **AI integration:** Gemini API for assisted narrative and classification. Numerical reporting remains based on inspectable source data and calculations.
- **Extraction & reporting:** Python, Playwright, BeautifulSoup, pandas, openpyxl, ReportLab and python-docx across the reporting toolchain.
- **Scheduling & delivery:** GitHub Actions and local launchd jobs in different workflows.
- **Additional implemented adapters:** NVIDIA, OpenRouter and GitHub Models appear in an alternative-provider chain. Successful live use of each adapter is not claimed here.

## Pescadería 19 y B — commerce & operations demo

- **Application:** React, TypeScript, Vite, HTML and CSS.
- **Data & server logic:** PostgreSQL, Supabase Auth, Edge Functions and Storage.
- **Deployment:** Firebase Hosting and GitHub Actions checks.
- **QA:** Playwright, Node.js tests and PGlite database tests.
- **Google setup:** Google Cloud Console and OAuth configuration; Google Search Console for website ownership verification. This is not a claim of running Search Console SEO analytics or its API.

The project is a presentation demo. The reviewed records leave real Google sign-in and final brand approval pending; configuration work and a fully validated login are different milestones.

## CRONO — local sports timing prototype

Python, SQLite, HTML, CSS, JavaScript, unittest and browser validation support the timing and management workflow. Google Stitch was used for design explorations. RFID is simulated in the demonstrable workflow; physical reader integration and accuracy remain pending.

## NotaLógica / The Seventh Voice — game & creative production

Flutter and Dart support the application, with Flame for game work and SoLoud for interactive audio. Google Stitch and Gemini-assisted visual explorations form part of the design history.

The creative production toolchain also includes MuseScore Studio, MuseSampler, FFmpeg, sfizz and music21 for score preparation, rendering and audio iteration. These are creative production tools, not backend services. The game remains in development.

## Cross-project workflow

Git and GitHub for version control; Claude Code and Codex for AI-assisted development; REST APIs, JSON, HTTP diagnostics and browser console/network inspection for integrations and investigations.

I select tools around a concrete workflow and distinguish a successful API response from a verified business outcome. Technology breadth complements the ability to explain a specific implementation; it does not replace it.
